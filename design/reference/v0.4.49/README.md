# Phone UI reference — v0.4.49

Screenshots of the phone app as shipped in v0.4.49, kept as the reference look for new and
reworked screens. When a screen is redesigned, match these: dark surfaces, rounded cards, tonal
icon chips, Thai copy, the accent blue for the primary action.
